# Chat-mode Playwright browser QA

This public kit contains the portable browser-QA implementation only. Project-specific provenance, acceptance evidence, screenshots, and verified private baselines are intentionally excluded.

## Usage guide

For the complete integration path from `portable/` to a working ChatGPT + GitHub Actions + Playwright verification loop in your own Web project, see [`USAGE_GUIDE.md`](USAGE_GUIDE.md).

Use `portable/` as the integration source for a target project. Re-run the full black-box QA cycle in that project before treating the adapted setup as verified.
